<h2><a href=https://www.codewars.com/kata/61c78b57ee4be50035d28d42/train/typescript target="_blank">Merge overlapping strings</a></h2><h3>7 kyu</h3><p>This kata requires you to write a function which merges two strings together. It does so by merging the end of the first string with the start of the second string together when they are an exact match.</p><pre><code>"abcde" + "cdefgh" =&gt; "abcdefgh""abaab" + "aabab" =&gt; "abaabab""abc" + "def" =&gt; "abcdef""abc" + "abc" =&gt; "abc"</code></pre><p>NOTE: The algorithm should always use the longest possible overlap. </p><pre><code>"abaabaab" + "aabaabab" would be "abaabaabab" and not "abaabaabaabab"</code></pre>
