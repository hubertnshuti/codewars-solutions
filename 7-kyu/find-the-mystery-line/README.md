<h2><a href=https://www.codewars.com/kata/67a11f616a791e028b86582f/train/typescript target="_blank">Find the mystery line</a></h2><h3>7 kyu</h3><p>Brush up on your Algebra while brushing up on your coding!</p><p>You receive a mystery function <code>f(x)</code> that accepts a single real number [1] and returns a single real number. For this kata, the mystery function will always be linear [2].</p><p>Your goal is to reverse-engineer the equation inside the mystery function. Return values will be of the form <code>[m, b]</code> [2].</p><pre><code class="language-ts">const exampleEquation = (x) =&gt; (2 * x) + 5; // y = 2x + 5findMysteryEquation(exampleEquation); // returns [2, 5];</code></pre><p>[1] Real number: Any positive, negative, or zero number; includes all types of decimals and fractions. For the purposes of this kata, use your language's version of a floating-point number.</p><p>[2] Linear: When graphed, the x and y coordinates will produce a straight line. This is usually represented as <code>y = mx + b</code>, where <code>m</code> is the slope and <code>b</code> is the y-intercept.</p>
