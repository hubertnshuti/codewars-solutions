<h2><a href=https://www.codewars.com/kata/5884731139a9b4b7a8000002/train/javascript target="_blank">Simple Fun #18: Candles</a></h2><h3>7 kyu</h3><h1 id="task">Task</h1><p> When a candle finishes burning it leaves a leftover. makeNew leftovers can be combined to make a new candle, which, when burning down, will in turn leave another leftover.</p><p> You have candlesNumber candles in your possession. What's the total number of candles you can burn, assuming that you create new candles as soon as you have enough leftovers?</p><h1 id="example">Example</h1><p> For candlesNumber = 5 and makeNew = 2, the output should be <code>9</code>.</p><p> Here is what you can do to burn 9 candles:</p><pre><code>burn 5 candles, obtain 5 leftovers;create 2 more candles, using 4 leftovers (1 leftover remains);burn 2 candles, end up with 3 leftovers;create another candle using 2 leftovers (1 leftover remains);burn the created candle, which gives another leftover (2 leftovers in total);create a candle from the remaining leftovers;burn the last candle.Thus, you can burn 5 + 2 + 1 + 1 = 9 candles, which is the answer.</code></pre><h1 id="inputoutput">Input/Output</h1><ul><li><p><code>[input]</code> integer <code>candlesNumber</code></p><p> The number of candles you have in your possession.</p><p> Constraints: 1 ≤ candlesNumber ≤ 50.</p></li><li><p><code>[input]</code> integer <code>makeNew</code></p><p> The number of leftovers that you can use up to create a new candle.</p><p> Constraints: 2 ≤ makeNew ≤ 5.</p></li><li><p><code>[output]</code> an integer</p></li></ul>
