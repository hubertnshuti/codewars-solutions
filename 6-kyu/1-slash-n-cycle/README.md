<h2><a href=https://www.codewars.com/kata/5a057ec846d843c81a0000ad/train/typescript target="_blank">1/n- Cycle</a></h2><h3>6 kyu</h3><p>Let <code>n</code> be an integer coprime with <code>10</code>, e.g. <code>7</code>.</p><p><code>1/7 = 0.142857 142857 142857 ...</code>.</p><p>We see that the decimal part has a cycle: <code>142857</code>. The length of this cycle is <code>6</code>. In the same way:</p><p><code>1/11 = 0.09 09 09 ...</code>. Cycle length is <code>2</code>.</p><h4 id="task">Task</h4><p>Given an integer <code>n (n &gt; 1)</code>, write a function that returns the length of the cycle if there is one, otherwise (if n and 10 not coprimes) return <code>-1</code>. </p><h4 id="examples">Examples</h4><pre><code>n = 5  --&gt; Should return -1n = 13 --&gt; Should return 6 -&gt; 0.076923 076923 076923 ...n = 21 --&gt; Should return 6 -&gt; 0.047619 047619 047619 ...n = 27 --&gt; Should return 3 -&gt; 0.037 037 037 037 037 037 ...n = 33 --&gt; Should return 2 -&gt; 0.03 03 03 03 03 03 03 03 ...n = 37 --&gt; Should return 3 -&gt; 0.027 027 027 027 027 027 ...n = 94 --&gt; Should return -1 </code></pre><h4 id="notes">Notes</h4><pre><code>n = 22 --&gt; Should return -1 since 1/22 ~ 0.0 45 45 45 45 ...</code></pre><ul><li>Please ask before translating..</li></ul>
