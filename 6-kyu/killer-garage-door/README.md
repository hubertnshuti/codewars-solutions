<h2><a href=https://www.codewars.com/kata/58b1ae711fcffa34090000ea/train/typescript target="_blank">Killer Garage Door</a></h2><h3>6 kyu</h3><h1 id="situation">Situation</h1><p>You have been hired by a company making electric garage doors. Accidents with the present product line have resulted in numerous damaged cars, broken limbs and several killed pets. Your mission is to write a safer version of their controller software.</p><h1 id="specification">Specification</h1><p>We always start with a closed door. The remote control has exactly one button, with the following behaviour.</p><ul><li>If the door is closed, a push starts opening the door, and vice-versa</li><li>It takes 5 seconds for the door to open or close completely</li><li>While the door is moving, one push pauses movement, another push resumes movement in the same direction</li></ul><p>In order to make the door safer, it has been equipped with resistance-based obstacle detection. When the door detects an obstacle, it must immediately reverse the direction of movement.</p><h1 id="input">Input</h1><p>A string where each character represents one second, with the following possible values.</p><ul><li><code>'.'</code> No event</li><li><code>'P'</code> Button has been pressed</li><li><code>'O'</code> Obstacle has been detected (supersedes P)</li></ul><p>As an example, <code>'..P....'</code> means that nothing happens for two seconds, then the button is pressed, then no further events.</p><h1 id="output">Output</h1><p>A string where each character represents one second and indicates the position of the door (0 if fully closed and 5 fully open). The door starts moving immediately, hence its position changes at the same second as the event.</p><h1 id="example">Example</h1><p><code>..P...O.....</code> as input should yield<code>001234321000</code> as output</p>
