<h2><a href=https://www.codewars.com/kata/52f78966747862fc9a0009ae/train/typescript target="_blank">Reverse polish notation calculator</a></h2><h3>6 kyu</h3><p>Your job is to create a calculator which evaluates expressions in <a href="http://en.wikipedia.org/wiki/Reverse_Polish_notation" data-turbolinks="false" target="_blank">Reverse Polish notation</a>.</p><p>For example expression <code>5 1 2 + 4 * + 3 -</code> (which is equivalent to <code>5 + ((1 + 2) * 4) - 3</code> in normal notation) should evaluate to <code>14</code>.</p><p>For your convenience, the input is formatted such that a space is provided between every token.</p><p>Empty expression should evaluate to <code>0</code>.</p><p>Valid operations are <code>+</code>, <code>-</code>, <code>*</code>, <code>/</code>.</p><p>You may assume that there won't be exceptional situations (like stack underflow or division by zero).</p>
