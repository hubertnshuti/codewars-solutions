<h2><a href=https://www.codewars.com/kata/527bbf9f8699010bf40006ee/train/javascript target="_blank">Functional Lists</a></h2><h3>6 kyu</h3><p>In this kata, you will create a simple, immutable, singly-linked list.</p><p>Most list implementations use mutable nodes.  Mutability brings with it a whole host of problems (especially in threaded environments, but even just with state saved and shared in multiple places).  When you shift to immutable nodes, you gain a new ability to reason about things.  If you have a list, it will never contain different things than it does at the moment.</p><p>However, when dealing with immutable nodes, one has to take special steps to try to maintain efficiency.  For example, to add a node to the beginning of a list, you don't want to have to duplicate the whole list.  You want to be able to share as many nodes of the list as possible between the original list and the newly generated list (while still being a singly-linked list).</p><p>There are two classes involved here:  <code>EmptyList</code> and <code>ListNode</code>. The <code>ListNode</code> constructor takes a <code>value</code> and a <code>next</code> parameter.  The <code>value</code> parameter can be anything.  The <code>next</code> parameter will be either a <code>ListNode</code> instance or an <code>EmptyList</code> instance representing the rest of the list after this node.</p><p>The <code>toString()</code> method should return <code>"()"</code> for an <code>EmptyList</code> and <code>"(1 2 3)"</code> for a list containing the numbers 1, 2, and 3.</p><p>The <code>isEmpty()</code> method will return <code>true</code> for <code>EmptyList</code> instances and <code>false</code> for the <code>ListNode</code> instances.</p><p>The <code>length()</code> method will return the number of non-<code>EmptyList</code> nodes in a list.</p><p>The <code>orig.push(x)</code> method will create a list whose first node contains the value <code>x</code> and where the new list shares as many nodes as possible with <code>orig</code> (while still being a singly-linked list).</p><p>The <code>orig.remove(x)</code> method will create a list where all nodes with value <code>x</code> are removed and which shares as many nodes as possible with <code>orig</code> (while still being a singly-linked list).</p><p>The <code>orig.append(other)</code> method will create a list which is a concatenation of all nodes in <code>orig</code> and all nodes in <code>other</code> and which shares as many nodes as possible with <code>orig</code> and <code>other</code> (while still being a singly-linked list).</p><p>If <code>orig.isEmpty()</code> returns false, then <code>orig.head()</code> should return the value in the first node of the list.  The <code>orig.tail()</code> should return the sublist of <code>orig</code> containing all of the nodes except the first node in <code>orig</code>.</p>
